# 생각별 선생님 v27 — 학부모 모드 개편

이 버전은 v26 과목 자동 분류와 학년별 힌트, v24 정답 판정, v23 스크롤, v22 안전한 힌트, v16 자동 재시도를 유지합니다.

## 이번 변경사항

- 학생 화면: AI 설정 버튼 숨김, 정답 보기 버튼 제거. 학년/힌트/문제 다시 읽기만 유지.
- 학부모 모드: 진입할 때 보호자 비밀번호를 서버에서 검증합니다. 초기 비밀번호는 **0000**이며, 로그인 후 아래쪽 **정답 보기 비밀번호**에서 변경하세요.
- 현재 문제에서 **성공한 힌트 5회**를 충족하면 학부모 모드 안의 **정답과 풀이 확인하기** 버튼이 활성화됩니다. 서버에서도 같은 조건과 비밀번호를 검사합니다.
- 정답은 학부모 모드 안에서만 표시되며 학생의 채팅 내역에 추가되지 않습니다. 학부모 모드를 닫으면 인증 상태가 사라집니다.
- 학부모 리포트: 문제별 과목, 스스로 최종 정답을 찾았는지, 중간 단계의 확인된 정답 횟수, 오답 시도, 힌트 사용 횟수를 바탕으로 **당일 관찰된 강점과 연습할 부분**을 요약합니다.
- 데이터가 적으면 이를 명시하며 **아이의 지능 또는 지속적인 능력을 평가하지 않습니다.** 자유서술형 AI 정답 판정에는 오류가 있을 수 있습니다.

## 개인정보/보안 주의

- 비밀번호 변경 정보는 기기별로 HttpOnly 암호화 쿠키에 저장되며, 다른 기기와 자동 공유되지 않습니다.
- **공개 출시 전에 반드시 0000을 강력한 비밀번호로 변경**하세요. 4자리 숫자는 강한 인증 수단이 아닙니다.
- 운영용 서버에서는 고정된 `ANSWER_PIN_SECRET` 환경변수를 추가하면 Render 배포 또는 AI 키 변경 후에도 보호자 비밀번호 쿠키를 안정적으로 복원하는 데 도움이 됩니다. 충분히 긴 무작위 비밀값을 설정하고 외부에 공개하지 마세요.
- 리포트는 현재 **기기 브라우저에 저장**되며 백엔드 사용자별 계정 데이터베이스가 아닙니다. 가정용 시제품으로 사용하고, 공개 상용화 시 사용자 인증 및 서버 저장을 보강해야 합니다.
- 이 버전은 학생의 AI 설정 **화면만 숨기는 것**입니다. AI 키는 여전히 Render 환경변수로 보호하며, 기존 API 호출 기능은 유지됩니다.
