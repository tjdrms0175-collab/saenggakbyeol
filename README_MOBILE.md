# 생각별 v8 · 휴대폰 설치형 앱 (PWA)

기존 v7의 모든 화면과 기능(힌트 무제한, 정답 확인, 사진 입력, 음성 인식, 여성 목소리, 무료 로컬 Ollama, Google Gemini 및 여러 API, 학부모 리포트)을 유지하면서 **홈 화면에 설치할 수 있는 PWA** 기능을 추가했습니다.

**이 ZIP은 APK/IPA가 아닙니다.** 휴대폰에서 실제로 설치하려면 웹앱을 HTTPS 서버에 올린 뒤 휴대폰에서 해당 웹주소를 열어야 합니다. ZIP 파일 자체를 휴대폰에 설치할 수 없습니다. 인터넷이 없을 때 저장된 데모 화면은 사용할 수 있으나 외부 AI/API, Gemini TTS 및 음성 인식은 네트워크에 의존할 수 있습니다.

## A. 노트북에서 실행 확인하기 (기존과 동일)

1. 기존 v7 서버 창에서 `Ctrl + C`로 종료합니다.
2. 새 ZIP 압축을 풉니다.
3. `ai_home_tutor/생각별-실행.bat` 실행, 또는 폴더 주소창에 `cmd` 입력 → `npm.cmd start` 실행합니다.
4. 크롬에서 `http://127.0.0.1:3000` 열기 → `Ctrl+Shift+R`로 새로고침합니다.
5. 상단 **앱 설치** 버튼에서 설치 안내가 표시됩니다. 단, 노트북의 localhost는 **휴대폰에서 같은 주소로 접근할 수 없습니다.**

## B. 휴대폰에서 잠깐 화면 미리보기 (동일 Wi-Fi, 마이크 제한)

1. 노트북과 휴대폰을 같은 Wi-Fi에 연결합니다.
2. `start_phone_preview.bat`을 실행하고 검은 창에 표시된 **IPv4 주소**(예: 192.168.0.25)를 찾습니다.
3. 휴대폰 브라우저에 `http://192.168.0.25:3000`처럼 입력합니다. 이 주소는 예시이며 **본인 컴퓨터의 IPv4**를 사용해야 합니다.
4. Windows 방화벽이 문의하면 개인 네트워크만 허용합니다. 접속이 실패하면 같은 Wi-Fi인지 확인합니다.
5. **주의:** HTTP LAN 주소는 보안 연결이 아니어서 마이크/홈 화면 앱 설치 기능이 제한될 수 있습니다. HTTP로 API 키를 입력하지 마세요. 브라우저 임시 API 키는 HOST가 0.0.0.0일 때 서버가 거부하며, 이 모드에서는 데모·노트북 Ollama 등만 테스트하세요.

## C. 휴대폰에 아이콘 설치해서 실제 앱처럼 사용하기 (HTTPS)

1. Node.js 웹 서버를 실행할 수 있는 호스팅에 `ai_home_tutor` 폴더 전체를 배포합니다. GitHub에 이 폴더만 저장소 루트로 업로드하면 `render.yaml`을 이용해 **Render Blueprint** 배포를 진행할 수 있습니다.
2. Render 같은 호스팅의 환경변수에 다음을 지정합니다(코드에 하드코딩하지 마세요).
   - `HOST=0.0.0.0`
   - `NODE_ENV=production`
   - `TRUST_PROXY=1` (HTTPS reverse proxy를 사용할 때만)
   - `APP_ACCESS_PIN=영문숫자 6자 이상 본인이 설정한 비밀번호`
   - `GEMINI_API_KEY=Google AI Studio에서 만든 본인의 API 키`
   - Render가 제공하는 `PORT`는 그대로 사용
3. 배포 완료 시 호스팅 업체가 제공하는 `https://...` 주소를 휴대폰에서 엽니다.
4. 접근번호를 입력하고, **AI 설정 → 외부 AI API 연결 → Google Gemini → 모델명 입력 → API 키 입력란은 공란(서버 환경변수 사용) → 적용**합니다.
5. **안드로이드 Chrome:** 오른쪽 상단 ⋮ → ‘앱 설치’ 또는 ‘홈 화면에 추가’ → 설치.
6. **아이폰 Safari:** 공유 버튼 → ‘홈 화면에 추가’ → 추가. 기종에 따라 ‘웹앱으로 열기’ 토글이 있을 수 있습니다.
7. 앱 아이콘을 누르면 주소창 없는 독립된 창에서 실행됩니다.

### 클라우드 배포시 중요한 점

- 앱은 클라우드에서 실행되는 **웹앱**입니다. 기존 노트북의 `Ollama`는 Render 클라우드에서 실행되지 않습니다. 모바일에서는 Gemini 등 외부 API를 선택하세요.
- Render Free 서비스는 유휴 상태에서 잠들어 첫 요청이 느릴 수 있습니다. 사용 여부, 요금, 신원 확인은 공급자의 정책에 따라 달라집니다.
- 외부 AI API는 무료 한도가 끝나면 요금이 발생할 수 있습니다. Gemini TTS는 별도 요금/할당량이 적용됩니다.
- 이 프로젝트는 소규모 개인 테스트용입니다. 어린이 대상 정식 공개 서비스에는 계정별 사용자 인증, 서버측 사용량 제한, 아동 개인정보 취급 안내, 부모 동의, 안전성 검증이 추가로 필요합니다.
- `APP_ACCESS_PIN`이 켜져 있으면 6자 이상의 접근번호를 입력해야 `/api/tutor` 등의 서버 기능을 사용할 수 있습니다. 이 인증은 개인 테스트를 위한 기본 잠금장치이지 전체 서비스 보안 시스템이 아닙니다.
- 개인 API 키를 GitHub에 올리지 마세요. `render.yaml`은 `sync: false`로 키 값을 코드와 분리합니다.
- 브라우저가 제공하는 음성 인식과 TTS는 단말기 및 브라우저에 따라 지원 범위가 다릅니다. iOS 웹앱에서는 음성 인식이 다르게 작동하거나 비활성화될 수 있습니다. 재생이 차단되면 답변 옆 ‘🔊 다시 듣기’를 직접 누르세요.
- 음성 인식은 브라우저 공급자의 온라인 서버에 전송될 수 있으며, Gemini 등 외부 API를 선택하면 질문·사진이 해당 업체로 전달됩니다.
- 학습 기록과 학년·과목·AI 제공업체·음성 설정(비밀 키 제외)은 **해당 휴대폰의 브라우저에만 저장**됩니다. 다른 기기와 자동 동기화되지 않습니다. API 키는 브라우저에 영구 저장하지 않습니다.

## D. 실행 파일의 차이

- `생각별-실행.bat` : 기존처럼 **노트북 전용** 루프백 서버 시작
- `start_phone_preview.bat` : 같은 Wi-Fi의 **휴대폰에서 UI 확인**을 위한 HTTP 미리보기
- `render.yaml` : HTTPS 환경에 배포하기 위한 구성 예시
- `manifest.webmanifest`, `sw.js`, `icon-*.png` : 휴대폰 홈 화면 설치를 위한 파일

## E. 점검 명령어

```powershell
cd ai_home_tutor
npm.cmd run check
npm.cmd start
```

`http://127.0.0.1:3000/api/health`에서 앱 버전 확인.
