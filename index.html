⚙ AI 설정

문제 전체를 AI가 분석하고 힌트를 한 번 더 검토해요. API 키는 Render 서버에서만 관리하며, 선생님 목소리는 별도 설정에서 변경할 수 있어요.

OpenAI 호환 Chat Completions API의 기본 주소를 입력하세요. /chat/completions는 자동으로 붙어요.

서버에 등록된 API 키 상태를 확인하고 있어요…

🔒 API 키는 이 앱에 입력하지 않습니다. Render → Environment에 등록된 키를 서버가 직접 사용합니다. 키 내용은 휴대폰으로 전달하지 않아요.

실제 AI 서버에 짧은 시험 질문을 보내므로 서비스 사용량이 발생할 수 있어요. 연결은 서버에 등록된 API 키로 진행합니다.

🔐 정답 보기 비밀번호

힌트를 5번 이상 받은 뒤 비밀번호를 입력하면 정답을 볼 수 있어요. 최초 비밀번호는 0000입니다. 처음 사용하실 때 변경해 주세요.

비밀번호 변경은 이 기기·브라우저에 저장돼요. 다른 기기에는 따로 설정해야 하고, 브라우저 데이터를 삭제하면 초기값으로 돌아갈 수 있어요.
