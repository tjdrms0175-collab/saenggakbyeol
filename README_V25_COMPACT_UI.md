# 생각별 선생님 v25 — 모바일 학습 화면 공간 개선

기존 v24의 Gemini 모델 자동 전환, 5회 뒤 정답 보기 비밀번호, 힌트 검증, 올바른 중간 답안 칭찬, 모바일 답변 위치 유지 기능을 그대로 제공합니다.

## 변경 내용
- AI 힌트 아래에 표시되던 `문제 이해: ...` 표시를 숨겼습니다. 서버의 문제 분석 및 검증은 유지됩니다.
- `힌트 더 받기` · `문제 다시 읽기` · `정답` 버튼을 모든 화면 크기에서 **한 줄 3열**로 배치했습니다.
- `이해했어요!`는 힌트 횟수 옆의 작은 버튼으로 옮겨 화면을 절약했습니다.
- `정답 (0/5)` → `정답 (5/5)` → `정답 보기`로 버튼 표시를 간결하게 변경했습니다. 실제 정답 공개는 여전히 **힌트 5회와 보호자 비밀번호**가 필요합니다.
- 서비스 워커 캐시 버전 변경으로 갤럭시 PWA에서 최신 화면이 표시되도록 했습니다.

## GitHub + Render 업데이트
업데이트 ZIP에 포함된 `index.html`, `styles.css`, `app.js`, `sw.js`를 GitHub 저장소의 같은 이름 파일과 교체하고 Commit하세요. Render에서 Live가 되면 갤럭시 앱을 완전히 닫고 다시 실행하세요. 이전 화면이 남는다면 먼저 브라우저에서 사이트를 새로 열고 앱을 재실행해 보세요. 학습 기록이 사라질 수 있으므로 **앱 데이터 삭제는 하지 마세요.**

Render의 `GEMINI_API_KEY` 및 다른 환경변수는 변경하지 않습니다.
