# 생각별 선생님 v22 — 정답 비노출·사고 단계 중심 힌트

## 이번 변경의 목적
v21에서는 AI에게 "정답을 알려주지 마세요"라고 지시하고 별도의 검토 AI가 힌트를 다시 읽었지만, 정답 숫자나 개념을 실제 답과 대조하는 서버 출력 보호가 충분하지 않았습니다.

v22는 **문제 이해 → 비공개 풀이·정답 확인 → 지금 할 사고 단계 하나 선정 → 별도 AI 검토 → 서버 출력 검사 → 힌트 표시** 순서로 작동합니다.

## 변경 사항
- 내부 정답은 서버 AI 검증에만 사용하고 브라우저로 전송하지 않습니다.
- AI 생성과 AI 검토 모두에서 현재 문제의 정답 및 동의 표현을 구조화해 비공개로 다룹니다.
- AI는 **쉬운 원리 한 문장 + 아이가 직접 할 한 가지 행동을 묻는 한 문장**을 만듭니다.
- 추가 힌트도 단계적으로 접근하되 답에 가까워졌다는 이유로 정답 숫자, 완성식, 정답 단어를 대신 말하지 않습니다.
- 검토 요청은 `safe_to_show`, `contains_answer`, `contains_complete_solution` 안전 플래그를 반드시 포함해야 하며, 누락되거나 불확실하면 거부합니다.
- 별도 서버 검사에서 정답 숫자, 한국어 숫자 표현(예: 마흔둘·사십이), 시간·점수 등의 결과, 직접 노출된 개념 단어, 완성된 수식 일부를 차단합니다.
- AI가 이해한 문제를 표시하는 설명(`problemFocus`)에 정답이 들어가도 안전한 일반 문구로 대체합니다.
- 부적절한 응답은 화면으로 보내지 않고 에러를 표시하며 **성공한 힌트 횟수로 계산하지 않습니다.**
- 아이가 직접 정답을 말했을 때의 정오 판정과 **힌트 5회 후 비밀번호로 정답 보기** 기능은 유지합니다.
- 기존 Gemini 3단계 전환, FreeLLMAPI 선택 연결, 음성 입력, 사진 입력, PWA, 질문 자동 재연결, 답변 시 화면 스크롤 정책은 유지합니다.

## 단계별 예시
문제: "12와 18의 최대공약수를 구하세요."
- 첫 힌트 예시: "약수는 나누었을 때 나머지가 없는 수예요. 먼저 12를 나누어떨어지게 하는 수부터 적어 볼까요?"
- 다음 힌트 예시: "두 수에 모두 들어맞는 약수를 찾으면 비교하기 쉬워요. 앞에서 적은 약수 중 18도 나눌 수 있는 것에 표시해 볼까요?"
- 이후: 아이가 표시한 공약수를 스스로 비교해 답을 말하도록 기다립니다. 선생님이 최종 수를 직접 말하지 않습니다.

## GitHub + Render 업데이트
1. `saenggakbyeol_v22_github_safe_hints.zip` 압축을 풉니다.
2. GitHub 저장소 최상위에 포함된 파일을 업로드하고 기존 파일을 교체한 뒤 `Commit changes`를 누릅니다.
3. **`hint-safety.mjs`는 새 파일이며 반드시 저장소 최상위에 추가해야 합니다.** `server.mjs`, `tutor-engine.mjs`, `package.json` 및 테스트 관련 파일도 함께 업로드해야 합니다.
4. Render가 새 커밋으로 배포하여 `Live` 상태인지 확인합니다.
5. 갤럭시에서 앱을 완전히 닫았다가 열고 **새 문제**를 누른 뒤 여러 단계의 힌트를 시험합니다.
6. Render 환경변수(`GEMINI_API_KEY`, `FREELLMAPI_...` 등)는 기존 값을 유지합니다.

## 검증과 제한 사항
- `npm run check`, `npm test`로 모의 AI 응답과 HTTP API 경로를 검증할 수 있습니다.
- 일반적인 힌트는 기존과 같이 AI API를 **두 번** 호출합니다(생성 + 검토). 위험한 응답은 노출하지 않고 실패 처리하므로 다시 요청해야 할 수 있습니다.
- 숫자·일부 정답 단어의 직접 노출은 코드로 막지만, 정답을 아주 자연스럽게 의역하거나 잘못된 비공개 답을 두 AI가 모두 고른 경우 등 **모든 우회·오판을 100% 막는 것은 아닙니다.** 실제 Gemini 계정과 대표 문제 세트로 출시 전 검증해야 합니다.
- 정답을 누출하지 않는 것과 잘 가르치는 것은 별도의 품질 목표입니다. 학생과 보호자가 좋은 힌트인지 피드백할 수 있는 기능은 추후 고려할 수 있습니다.
