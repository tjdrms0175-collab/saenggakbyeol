# 생각별 선생님 v19 — 첫 화면 접근번호 제거

- 시작할 때 나오는 ‘생각별 비밀번호’ 팝업을 제거했습니다.
- Render 서버에서도 APP_ACCESS_PIN 로그인을 요구하지 않습니다. 기존 Render의 APP_ACCESS_PIN은 지우지 않아도 되며, 다른 기기에서 변경한 정답 확인 PIN 쿠키의 암호화 키 호환용으로 남겨둡니다.
- 정답 보기 기능은 그대로 **동일 문제의 힌트 5회 이상 + 보호자 PIN(처음 0000)** 을 요구합니다.
- Gemini API 키는 계속 Render 환경변수에만 보관됩니다.
- 공유 접근번호를 제거한 만큼 API 사용량을 보호할 기본 제한을 추가했습니다. `AI_CLIENT_HOURLY_LIMIT` 기본 40요청/IP/시간, `AI_GLOBAL_DAILY_LIMIT` 기본 120요청/서버/UTC 날짜. 사용자 단위 인증이 아닌 간단한 메모리 기반 제한이며 Render 서버 재시작 시 초기화됩니다.
- 웹 공개 상태에서는 누구나 생각별 API를 호출해 서버 사용량을 소비할 수 있습니다. 실서비스 출시 전 보호자 계정, 비용 예산 알림, 지속 저장되는 사용량 제한, 아동 개인정보 보호 조치가 필요합니다.

## 갤럭시 배포
1. GitHub 업데이트 ZIP에 들어 있는 파일을 저장소 최상위에 업로드하고 Commit 합니다.
2. Render Deploys에서 새 버전 Live 확인. 기존 GEMINI_API_KEY는 그대로 유지합니다.
3. 갤럭시 생각별 앱을 완전히 종료 후 실행합니다. 예전 팝업이 나타나면 앱 캐시를 새로고침하거나 재실행합니다.
4. 5번의 힌트를 받은 뒤 정답 보기 보호자 PIN이 여전히 필요한지 확인합니다.

## 보안 주의
APP_ACCESS_PIN을 없애면 예전의 공용 로그인 보호는 사라집니다. 기본 IP/일일 제한은 배포 전용 임시 방어 수단이지 결제 사용자별 인증을 대신하지 않습니다.
