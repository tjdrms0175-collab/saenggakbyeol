# 생각별 선생님 v24 — 맞는 답인데 오류로 처리되는 문제 수정

## 문제
아이가 힌트에 대한 답을 직접 말한 경우에도, AI가 이어서 제안한 힌트에 정답이 포함되어 있으면 전체 요청을 실패 처리하고 `정확하지 않은 힌트는 보여주지 않을게요`라는 안내가 나오는 오류가 있었습니다.

## 해결 내용
1. **원문 최종 정답**과 **직전 힌트 질문에 대한 중간 단계 정답**을 따로 평가합니다.
2. 두 번의 AI 평가가 일치하면 맞은 단계는 `정답이야! (O)`로 칭찬합니다.
3. 아이가 맞힌 뒤 AI가 새로 제안한 힌트가 정답을 노출한다면 그 문장은 차단합니다. 이미 맞힌 학생의 정답 판정은 취소하지 않고, 안전한 다음 질문을 보여줍니다.
4. `가시`처럼 한 단어로 답한 경우 모델이 이를 힌트 요청으로 오분류하더라도, 두 AI 검토가 일치한 경우에는 정답으로 인정합니다.
5. 원문 전체 정답 확인 시에만 기존처럼 문제 완료 처리합니다. 중간 단계 정답은 다음 학습 단계로 이어집니다.
6. 기존 **힌트 5회 후 보호자 비밀번호로 정답 보기**, 무제한 힌트, 정답 숨기기, 세 모델 순차 전환, 모바일 스크롤 개선을 유지합니다.

## 적용 방법
기존 Render 앱이 배포된 GitHub 저장소 최상위에 다음 파일들을 업로드해 교체하세요.
- `tutor-engine.mjs`
- `server.mjs`
- `app.js`
- `sw.js`

Commit한 뒤 Render 배포가 Live 상태가 되면 갤럭시 앱을 완전히 종료하고 다시 켜세요. 앱의 예전 버전이 보인다면 앱 정보에서 캐시를 정리하고 다시 실행해 보세요(학습 기록 저장 방식에 따라 데이터가 사라질 수 있으니 **데이터 삭제는 하지 마세요**).

Render의 `GEMINI_API_KEY` 등 환경변수는 수정할 필요가 없습니다.

## 테스트
`npm run check` 및 `npm test`: **총 50개 통과**. `가시`라는 중간 답안, 위험한 후속 힌트, 최종 답 일치, 불일치, 일반 힌트 정답 노출 차단, 실제 로컬 서버 HTTP 요청 테스트를 포함합니다.

실제 Gemini 서비스의 응답은 API 키가 없어 재현하지 못했습니다. AI가 오답을 정답으로 잘못 판정할 가능성도 완전히 제거할 수는 없습니다.
