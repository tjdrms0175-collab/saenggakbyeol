# 생각별 선생님 v14 — 5회 힌트 후 보호자 정답 보기

## 변경 사항

- 기존 v13의 AI 원문 분석 → 힌트 생성 → 독립 검토 기능과 모바일 PWA·음성 기능 유지
- 정답 보기 버튼은 **같은 문제의 성공적인 힌트가 서버에서 5회 확인된 뒤** 활성화
- 정답 공개 요청은 서버에서 5회 확인과 정답 보기 비밀번호(초기값 `0000`) 검사를 모두 통과해야 함
- 보호자의 별도 승인 후 AI가 정답을 생성하고 두 번째 AI 검토가 일치해야 공개
- **AI 설정 → 정답 보기 비밀번호**에서 현재 비밀번호를 입력해 숫자 4~12자리의 새 비밀번호로 변경 가능
- 학습 리포트에 보호자의 정답 열람 기록 표시

## 기존 Render·갤럭시 앱 업데이트

1. `v14_github_update.zip`의 파일을 압축 해제합니다.
2. GitHub 저장소 최상위에 파일 7개(`app.js`, `index.html`, `server.mjs`, `tutor-engine.mjs`, `styles.css`, `sw.js`, `package.json`)를 기존 파일과 같은 이름으로 업로드/교체합니다.
3. GitHub에서 **Commit changes** 합니다.
4. Render에서 새 배포 상태가 **Live**인지 확인합니다.
5. 갤럭시의 생각별 앱을 완전히 종료했다 다시 열고, 갱신되지 않으면 Chrome에서 해당 사이트를 강력 새로고침하세요.
6. 첫 문제에 대해 힌트를 5번 받고 '정답 보기' 버튼을 누른 뒤 `0000`으로 확인합니다.
7. **AI 설정**에서 가능하면 즉시 초기 비밀번호를 변경하세요.

Render에 기존 `GEMINI_API_KEY`, `APP_ACCESS_PIN`, `TRUST_PROXY`가 설정되어 있다면 다른 API 환경변수를 추가할 필요는 없습니다.

## 중요한 제한

- **정답 보기 비밀번호와 Render 접속번호 `APP_ACCESS_PIN`은 서로 다른 비밀번호**입니다.
- 새로 변경한 정답 보기 비밀번호는 **이 브라우저/기기에만 저장**됩니다. 다른 기기에서는 기본 `0000`부터 다시 설정해야 합니다. 브라우저 데이터나 쿠키를 지우면 초기값으로 돌아올 수 있습니다. 갤럭시·Chrome·PWA 간에도 저장소가 다를 수 있습니다.
- 초기 비밀번호 `0000`은 추측하기 쉬우므로 강한 학부모 인증 수단이 아닙니다. 모든 기기에서 동일하게 적용되는 견고한 부모 인증을 원하면 별도 데이터베이스와 계정 시스템이 필요합니다.
- Render 무료 인스턴스가 재시작하면 메모리에 기록된 **해당 문제의 힌트 횟수**가 초기화됩니다. 아이는 새로 힌트를 받아야 할 수 있습니다.
- 모델이 확실한 단일 정답을 도출하지 못하거나 두 번의 검토가 일치하지 않으면 공개하지 않습니다. AI 검증 자체에도 오류 가능성이 있습니다.
- 정답 공개에는 별도 AI 호출 2회가 추가로 발생할 수 있으며 API 사용량이 증가합니다.
- 일반 채팅에서 AI가 정답을 누출하지 않도록 지시·검토하지만 생성형 AI의 모든 우회 가능성을 막는 절대적 보안 수단은 아닙니다.
