# 생각별 선생님 v28 — 중간 단계 정답과 원문 최종 정답 구분

## 수정 이유
아이의 답변이 직전 선생님 힌트에는 맞아도, 원래 문제에서 마지막으로 물은 정답과 다를 수 있습니다. 기존 버전은 AI 초안/검토가 모두 `correct`로 오판하면 최종 정답으로 잘못 기록했습니다.

## 수정 내용
- 학생 답은 원문의 최종 정답과 직전 힌트에 대한 중간 답으로 **독립 판정**합니다.
- 숫자 최종 답으로 판정하려면 AI 두 단계의 비공개 최종 정답과 학생 숫자가 일치해야 합니다. 답 검증에 이용한 숫자는 학생 화면에 노출하지 않습니다.
- `어떤 수에 7을 곱해야 하는데 7을 더해서 21이 나온` 형태의 원문에서는 잘못된 연산을 되돌려 구한 값과 바르게 계산한 최종 값을 **서로 구분하는 보조 수학 검산**을 적용합니다. 이 검산은 힌트를 생성하는 데 쓰지 않으며, 특정 문장 형태 외에는 함부로 정답을 추측하지 않습니다.
- 서술형 답도 단순 `correct` 표시에만 의존하지 않고 비공개 최종 답이나 검토된 대체 표현과 일치하는지 확인합니다. 판단 근거가 부족하면 문제 해결 완료로 기록하지 않습니다.
- 직전 힌트의 정답만 맞혔다면 `step_correct`로 반환하고 **원래 문제를 해결한 것으로 기록하지 않습니다**.
- 이 경우 다음 힌트는 수학 문제의 다음 한 단계로 이어지며, 다른 과목의 '특징/역할' 등 무관한 설명을 출력하지 않습니다.
- v27의 학년 선택, 과목 자동 인식, 학부모 모드, 힌트 5회 후 정답 보기와 비밀번호, Gemini 3단계 전환, 모바일/PWA 스크롤 등은 유지합니다.

1. `saenggakbyeol_v28_github_update.zip`을 압축 해제합니다.
2. 파일을 기존 GitHub 저장소 **최상위**의 같은 이름 파일과 교체합니다.

4. 갤럭시의 생각별 앱 종료 후 재실행. 이전 화면이 보이면 앱 캐시 새로고침.
