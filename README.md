# 생각별 선생님 v7 — 상냥한 여자 선생님 목소리

v6의 모든 기능을 유지한 버전입니다. 목소리 설정은 채팅창 아래 **🌷 선생님 목소리 설정** 버튼에 있습니다.

## 목소리 설정

- **무료 브라우저 목소리(기본)**: 현재 브라우저에 존재하는 한국어 음성을 검색해 여성·자연 음성을 우선 선택합니다. Chrome보다 **Microsoft Edge**에서 한국어 Online (Natural) 목소리가 제공되는 경우가 있습니다. 제공 여부는 컴퓨터/브라우저/네트워크 환경에 따라 다릅니다.
- **목소리 미리 듣기**: AI 연결 없이 무료 음성 샘플을 재생합니다. 음성 목록에서 원하는 목소리를 수동으로 고를 수 있습니다.
- **Gemini 자연 음성(선택)**: Google Gemini 3.8 Flash-Lite TTS API를 사용합니다. **별도 TTS 모델, 별도 사용량/요금이 발생할 수 있습니다. 무료가 아닐 수 있습니다.** 사용자가 명시적으로 선택했을 때만 요청합니다. Gemini API 키가 필요하며, 일반 채팅에 사용하는 모델명과는 다른 모델을 호출합니다. 키는 서버 환경변수 `GEMINI_API_KEY` 또는 음성 설정 입력창에서 제공합니다. 이 경우 답변 문장이 Google로 전송됩니다.
- **기본값**: 별도 요금이 없는 브라우저 음성 모드입니다. Gemini 음성 모드는 자동으로 켜지지 않습니다.

## 실행

Windows에서 `ai_home_tutor/생각별-실행.bat` 더블클릭 → http://127.0.0.1:3000 접속. 기존 서버가 실행 중이면 먼저 Ctrl+C로 종료하세요. 음성 설정 변경을 반영하려면 Ctrl+Shift+R.

## 주의사항

- 브라우저 기본 음성이 남성일 수도 있습니다. `getVoices()` API는 성별을 명시하지 않는 경우가 많아 이름 기반 추정으로 우선순위를 정합니다. 원하는 여성 음성을 보장할 수는 없으므로 **목소리 미리 듣기**를 사용하세요.
- Gemini TTS API 테스트는 실제 API 키 없이 모의 응답으로 수행했으며, 계정 권한·요금제·지역에 따라 실제 호출이 실패할 수 있습니다. 실패하면 오류를 표시하고 무료 브라우저 음성을 선택해서 사용할 수 있습니다.
- 기존 음성 질문은 Chrome 또는 Edge 음성 인식 서비스를 사용하며, 인식된 말은 서비스 공급자에게 전달될 수 있습니다.

# 생각별 선생님 v6 — 듣기 연장 · 힌트 무제한 · 정답 확인 · 자세한 힌트

초등학생을 위한 힌트 중심 AI 선생님입니다. **기존 v5.1의 음성 질문/읽어 주기, Ollama, Google Gemini, Claude, OpenRouter 등 다중 API, 사진 첨부, 학년/과목 선택 및 학부모 리포트를 유지**하면서 네 가지 사용성 요구를 반영했습니다.

## 이번 변경사항

1. **음성 입력을 더 오래 듣습니다.** 시작하고 말할 때까지 최대 15초 기다립니다. 말한 내용이 인식된 뒤 5.5초 동안 새 말이 없을 때 마무리하며, 브라우저 음성 인식이 일찍 종료되면 허용되는 범위에서 자동 재시작합니다. 다시 누르면 수동 종료합니다. *Web Speech API 자체의 인식 종료 정책과 네트워크에 따라 정확한 시간은 달라질 수 있습니다.*
2. **힌트 무제한.** 1~5회에서 멈추지 않고 6·7·20회 이후에도 계속 요청할 수 있습니다. 인터페이스는 `N회 · 무제한`으로 바뀝니다. 여러 번 계속 누르면 소재와 방법은 순환될 수 있지만 횟수 제한은 없습니다.
3. **아이가 직접 제출한 답을 확인.** 명확한 사칙연산이나 시간 변환 답은 서버에서 직접 계산해 판별합니다. 답이 맞으면 `정답이에요!`라고 칭찬하고 정답을 다시 말하지 않습니다. 틀리면 다음 힌트로 유도합니다. 기타 교과나 자유서술형은 선택한 AI가 판단하되, 애매한 경우 정답 확정을 피하도록 지시했습니다. **AI의 자유서술형 판정은 틀릴 수 있으며, 모든 유형을 자동 채점하지는 못합니다.** 학부모 리포트에 `정답 확인` 건수를 추가했습니다.
4. **더 상세한 힌트.** 힌트마다 문제에서 실제로 해야 할 행동, 수치·단위의 관계, 그림이나 비유를 설명한 뒤 유도 질문을 제시하도록 개선했습니다. 답을 대신 완성하는 것은 여전히 금지합니다.

## 윈도우에서 새 버전 설치

1. 이전 웹사이트의 검은색 서버 창에서 `Ctrl + C`를 눌러 종료하세요.
2. 이번에 받은 ZIP 파일을 압축 해제합니다. **이전 폴더에 덮어쓰지 말고** 새 `ai_home_tutor` 폴더에서 시작하세요.
3. `ai_home_tutor` 안의 **`생각별-실행.bat`**을 더블클릭하세요.
4. 크롬/엣지에서 **http://127.0.0.1:3000**을 열고 `Ctrl + Shift + R`을 눌러 새로고침하세요.
5. **AI 설정**에서 데모, 무료 Ollama 또는 Gemini 등 API 제공업체를 다시 선택하세요. API 키는 서버 파일에 저장되지 않으므로 새로운 페이지에서는 필요 시 다시 입력해야 합니다.

BAT 실행이 안 될 때: `ai_home_tutor` 폴더 위의 주소창에 `cmd`를 입력하고 Enter → 검은 창에서 `npm.cmd start`를 입력하세요. Node.js 20 이상 필요. Ollama 모드는 모델 설치가 필요하지만 외부 API 모드는 Ollama 설치가 필요하지 않습니다.

## Gemini 등 외부 API 연결

`AI 설정` → `외부 AI API 연결` → 공급업체 → 해당 계정에 실제로 제공되는 모델 ID → API 키 → `API 연결 테스트` → `설정 적용하기`.

Gemini 기본값은 이 프로그램에 지정한 **예시 모델명**입니다. 사용할 수 있는 정확한 ID는 **Google AI Studio 또는 공식 API 모델 목록**에서 계정별로 확인해야 합니다. API 연결 테스트는 실제 사용량을 소모할 수 있습니다. Gemini, OpenAI, Claude, OpenRouter, Groq, DeepSeek, Mistral, Together, xAI 및 사용자 지정 OpenAI 호환 API를 지원합니다.

## 테스트 문제

- `7 × 6은 어떻게 생각해야 하나요?` → 힌트를 7~8회 눌러도 중단되지 않는지 확인하세요. 이어서 `42`를 직접 입력하면 `정답이에요!`라고 응답하는지 확인하세요.
- 새 문제에서 `70분을 몇 시간 몇 분으로 나타내나요?` → `1시간 20분`은 더 생각하도록 유도하고, `1시간 10분`은 정답이라고 인정하는지 확인하세요.
- 🎤 `말로 질문` 버튼 → `70분을 ...`처럼 중간에 3~4초 쉬면서 질문하세요. 말을 마친 뒤 약 5.5초 동안 인식 결과가 이어지는지, `다시 듣기`로 선생님의 음성을 들을 수 있는지 확인하세요.
- **학부모 모드**에서 정답 확인 수가 표시되는지 확인하세요.

## 한계와 개인정보

- 브라우저의 Web Speech API는 마이크 인식 서비스를 브라우저 공급자의 서버에서 처리할 수도 있습니다. **음성 질문까지 완전한 오프라인 작동을 보장하지 않습니다.** 최신 크롬/엣지와 마이크 접근 허용이 필요합니다.
- 외부 API 모드에서 아이의 질문과 선택한 사진은 해당 제공업체로 전송됩니다. API 키는 로컬 탭에 임시 보관되며 로컬 서버를 경유해 사용됩니다. 여러 사용자에게 공개할 서비스라면 별도의 서버 인증, 키 보관·권한 관리가 필요합니다.
- 데모 모드는 주로 수학과 준비된 예시로 동작하며 실제 AI가 아닙니다. Ollama 소형 모델은 정확도가 낮을 수 있습니다.
- 자동 정답 검증은 **명확한 답안에서만** 작동합니다. 정답 노출을 막는 출력 필터도 완벽하지 않으므로, 실제 아동에게 사용하기 전 보호자가 여러 문제를 시험하세요.
- 오늘의 기록은 해당 브라우저 탭의 세션 저장소에 남습니다. `이해했어요`는 아이가 직접 표시한 것이며 정답 확인과 구분됩니다.

### 개발자 확인

- `npm.cmd run check` — JavaScript 구문 검사
- `npm.cmd start` — 로컬 서버 시작
- GET `/api/health` — 앱 및 서버 버전 확인
- POST `/api/tutor` — 힌트/답 판별 응답 JSON: `{ "hint": "...", "verdict": "correct | incorrect | uncertain" }`
