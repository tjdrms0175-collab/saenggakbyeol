# 생각별 선생님 v43 — 학부모 등록 코드 제거

기존 v42의 힌트, 사진, 음성, 신고, Gemini 비용 제한, Supabase 사용량 저장을 유지하며 **학부모 최초 설정 시 별도 등록 코드 입력을 제거**했습니다.

- 최초 설정: 숫자 6~12자리의 안전한 학부모 PIN을 두 번 입력하고 보호자 확인란 체크.
- 이후에는 같은 브라우저에서 설정된 PIN으로 학부모 모드에 입장합니다.
- 기존 PIN 쿠키는 유지되므로 기존 학부모는 설정된 PIN을 계속 사용합니다.
- **주의:** 쿠키 삭제, 다른 브라우저, 시크릿 창에서는 누구나 새 PIN을 만들 수 있습니다. 학부모 실명/성인 인증 기능은 아닙니다. 정식 아동용 앱 출시 전 보호자 인증과 이용약관 검토가 필요합니다.
- Render에서 `GUARDIAN_ENROLLMENT_CODE`를 삭제한 상태 그대로 운영할 수 있습니다. Supabase SQL 변경과 다른 환경변수 변경은 필요 없습니다.

## 배포

1. 이 ZIP을 풀어 GitHub 저장소의 루트 파일들을 교체한 뒤 Commit합니다.
2. Render Deploys에서 최신 커밋의 Live를 확인합니다.
3. 시크릿 창에서 학부모 모드의 등록 코드 항목이 없어졌는지 확인합니다.
4. PIN 6~12자리 신규 설정, 재입장, 기본 0000 차단, 힌트/사진/신고 기능을 확인합니다.
5. 앱이 예전 화면을 보이면 강력 새로고침하거나 홈 화면 앱을 다시 실행합니다.

기존 상세 문서는 `README_V42_GUARDIAN_PRIVACY_FEEDBACK.md` 등에 보관되어 있으나 **등록 코드 관련 내용은 과거 v42 안내**입니다.
