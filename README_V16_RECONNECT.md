# 생각별 선생님 v16 — 자동 재연결 업데이트

## 무엇이 달라졌나요?

- Gemini, FreeLLMAPI 등의 AI 요청이 일시적으로 **HTTP 503/502/504/500/408**으로 실패하면, 같은 요청을 자동으로 다시 시도합니다.
- 연결 실패 후 **약 4초, 8초, 16초, 32초, 64초, 최대 120초**로 대기 시간을 늘립니다. 동시에 요청이 몰리지 않도록 약간의 무작위 대기 시간을 추가합니다.
- AI로부터 정상 힌트가 돌아오면 **즉시 재시도 종료**합니다. 다음 질문에서 다시 일시적인 오류가 생기면 새로운 자동 재연결을 시작합니다.
- 학습창의 `재연결 중지` 버튼이나 AI 설정의 `재연결 중지` 버튼으로 언제든 대기와 재시도를 중단할 수 있습니다.
- 서버는 `503`을 `502`로 바꾸지 않고, 재시도 가능 여부 및 짧은 `Retry-After`를 브라우저에 전달합니다.
- 반복된 같은 요청에는 같은 `retryRequestId`를 사용하며, 서버에서 **중복된 힌트 카운트를 방지**하고 이미 성공한 응답을 재사용합니다.

## 재시도하지 않는 오류

- 401/403: API 키·접근 권한 오류
- 400/404/422: 모델명·요청 형식 오류
- 429: 무료/유료 사용량을 넘겼을 수 있으므로 기본적으로 자동 무한 재시도하지 않습니다. 제공업체에서 짧은 `Retry-After`를 준 경우에만 최대 3차례 제한적으로 시도합니다.
- 모델이 문제를 잘못 해석하거나 출력한 JSON 형식이 틀린 경우도 무작정 무한 재시도하지 않습니다.

## 갤럭시 앱에 적용하기

1. 기존 GitHub 저장소의 루트에 [v16 GitHub 업데이트 ZIP] 안의 파일을 같은 이름으로 덮어씁니다.
2. GitHub에서 `Commit changes`를 누릅니다.
3. Render 서비스의 배포가 `Live`가 되었는지 확인합니다.
4. 갤럭시에서 생각별 앱을 닫고 다시 열어 봅니다. 변경이 보이지 않으면 브라우저의 웹앱 새로고침을 진행합니다.
5. 기존 `GEMINI_API_KEY`, `FREELLMAPI_BASE_URL` 등 **Render 환경변수는 바꾸지 않아도 됩니다.**

## 시험하기

- `API 설정 → API 연결 테스트` 또는 학습창에서 질문할 때 503이 발생하면 자동 재시도 문구와 중지 버튼이 보입니다.
- 잠시 뒤 API가 회복되면 정상 답변을 화면에 출력하고 재시도를 종료합니다.
- 안정적인 API 사용 중에는 별도의 주기적 AI 요청을 보내지 않습니다.
- 중복 요청 방지·503 회복·401 차단·429 대기 지침은 로컬 모의 테스트로 확인했습니다.

## 제한 및 비용 주의

- 브라우저를 종료하거나 갤럭시 운영체제가 앱을 백그라운드에서 중단하면 **자동 재연결도 중단**됩니다. 서버가 다운된 동안 푸시를 보내거나 앱을 깨우는 백그라운드 작업은 포함되어 있지 않습니다.
- 재시도마다 외부 제공업체에 추가 요청할 수 있어 API **사용량/요금**이 증가할 수 있습니다. 중지 버튼을 제공하는 이유입니다.
- 일부 실제 응답은 이미 서버에 처리되었지만 통신만 끊길 수 있으므로, 중복 요청을 줄이기 위한 서버 캐시는 프로세스 메모리에서 30분간 유지합니다. Render 재시작 시 사라집니다.
- 실제 Google 서버 혼잡 상황에서 100% 복구되는지 검증할 수 없고, 공급자 장애·권한·한도 문제가 계속되면 복구되지 않을 수 있습니다.
