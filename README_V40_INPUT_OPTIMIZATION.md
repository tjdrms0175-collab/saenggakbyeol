# 생각별 선생님 v40 — Gemini 입력량 절약

## 이번 수정 내용

- 한 번의 힌트에서 두 번 호출하는 **초안 + 독립 검토**를 유지하면서 각 단계의 반복 학년·과목 지시문을 짧고 구체적으로 정리했습니다. 서버의 정답 비공개 검사, 학년 맞춤 방법, 과목 자동 판별, 중간 답/최종 답 구분, 틀린 조건 검사, 기존 재시도/할당량 제한은 유지했습니다.
- 원본 문제를 `original_problem_verbatim`으로 한 번 보내고, 최근 대화에 같은 문제 첫 메시지가 있을 경우 제거했습니다. 최근 작은 질문과 학생의 마지막 답변은 유지합니다. 단계별 지시는 시스템 지시문에만 넣고 사용자 JSON에는 반복하지 않습니다.
- 과거 대화를 최근 5개(각 최대 280자)로 줄입니다. 앱도 최근 8개까지만 서버에 전달합니다. 서버에서만 최종적으로 제한합니다.
- **이미 학생이 확인한 사진**은 새 힌트 요청마다 전체 이미지를 재업로드하지 않고 확인한 텍스트를 전송합니다. 이는 앱/Render 네트워크 사용량 절감이며, v39 서버도 이미지 자체를 Gemini 힌트 단계에 재전송하지 않았으므로 사진 기능의 Gemini 토큰 감소를 과장해서는 안 됩니다.
- Render의 `[gemini-usage]` 로그에 기존 `input`, `output`, `thinking`, `total` 외에 `cached` 값을 추가했습니다. 이 값은 Google 응답의 `usageMetadata.cachedContentTokenCount`에서 가져옵니다. 학생 문제·원문·사진·AI 답변은 로그에 넣지 않습니다.

## 입력 절감 예시

동일한 예시 문제와 학년, 짧은 문답에 대해 API에 실리는 프롬프트 **문자 수**(시스템 지시문 + 사용자 JSON)의 합계는 다음과 같았습니다.

- v39: 초안 5,672+966자 / 검토 4,395+1,141자 = **12,174자**
- v40: 초안 2,101+256자 / 검토 1,863+387자 = **4,607자**
- 텍스트 길이 기준 약 **62% 감소**. 이는 토큰 절감률이나 청구액 절감률과 같지 않습니다. 실제 토큰은 모델 응답 메타데이터와 Google AI Studio 사용량으로 확인하세요.

## 컨텍스트 캐싱 안내

Google Gemini의 **암묵적(implicit) 컨텍스트 캐싱**은 지원 모델에서 자동으로 작동하며 별도 설정이나 요금 선결제가 필요하지 않습니다. 요청에 동일한 지시문 시작 부분이 반복되면 캐시 적중 가능성이 높지만 **캐시 적중은 보장되지 않습니다**. v40은 학년별로 안정적인 지시문 시작 부분을 사용하고, 캐시 적중 토큰을 로그로 기록합니다.

**명시적(explicit) 캐시**를 무조건 생성하지 않았습니다. 생성과 시간별 저장 비용, 최소 캐시 크기, 모델별 호환성 때문에 짧은 학습 문제/소규모 운영에서 오히려 비용이 늘 수 있기 때문입니다. 필요하면 실제 실적을 보고 별도로 실험하세요.

## 배포 순서

1. 먼저 Render / Supabase에서 기존 환경변수는 그대로 둡니다. v40은 새 환경변수나 SQL을 요구하지 않습니다. 다만 v39의 신고 기능을 사용하려면 Supabase 서울 프로젝트 SQL Editor에서 이전에 전달한 `SUPABASE_SETUP_V39.sql`을 먼저 실행해야 합니다.
2. `saenggakbyeol_v40_full_github.zip`의 압축을 해제하고 **압축 내부의 파일들**을 GitHub `saenggakbyeol` 저장소 최상위에 업로드하여 기존 파일과 교체하고 Commit합니다. 이미 v39가 배포된 경우에는 patch-only ZIP으로 변경 파일만 교체할 수 있습니다.
3. Render Deploys에서 최신 Commit이 `Live`인지 확인하세요.
4. 휴대폰에서 새 문제 1개, 다음 힌트 1개, 아이가 짧게 답한 후 정오 피드백 1개, 사진 인식 후 글자 확인 1개, 신고 버튼 1개를 확인하세요. 비밀번호는 **공개된 기본 비밀번호가 없는지** 확인하세요. 실제 Gemini 답변 품질은 자동 모의 테스트만으로 보장되지 않습니다.
5. Render Logs에서 `[gemini-usage] model=... stage=... input=... output=... cached=...` 항목을 확인하세요. 로그가 없으면 `GEMINI_USAGE_LOG`가 `0`인지 확인하되, 학생 텍스트·API 키는 로그나 대화에 공개하지 마세요.
6. Google AI Studio에서 사용 모델 필터와 같은 비교 기간의 입력/출력 토큰, 비용, 캐시 적중 현황을 확인하세요. 프롬프트가 짧아졌어도 실제 비용은 사용량·모델·검증 재시도에 좌우됩니다.

## 안전성 / 현재 한계

- `npm run check`와 `npm test` 실행 결과 **98개 통과**(모의 API/데이터베이스 테스트). 라이브 Gemini AI의 힌트 정확도·품질은 배포 후 별도 확인해야 합니다.
- 사진을 사용해 읽은 문제는 여전히 학생에게 먼저 인식 문장을 보여주고 확인받습니다.
- 보호자 PIN 및 신고/개인정보 안내 기능은 v39 그대로 유지합니다. 아직 보호자 신원·아동 보호 정책 완성이나 실제 Play 심사 통과를 보장하지 않습니다.
- 요금 지출을 차단하는 절대적 수단이 아니므로 Google AI Studio의 월 지출 한도(사용자가 설정한 10달러)와 Render/Supabase 사용량 제한을 유지하세요.
