# 생각별 선생님 v35: 학년 맞춤 단계별 힌트와 객관식 정답 노출 방지

- v34 사진 인식·정답 잠금·학부모 모드·음성 인식 유지
- 초1~2: 생활 속 관찰 하나, 초3~4: 두 조건 비교, 초5~6: 원인·결과와 보기의 근거 한 가지 검토
- 첫 힌트는 정답 보기의 핵심 원인을 알려 주지 않고 현상의 바탕이 되는 관찰·시간의 차이부터 확인
