# 생각별 선생님 v33 — 갤럭시 촬영 후 사진 첨부 개선

## 변경 내용

- **사진 첨부 → 카메라로 촬영** 시, 외부 카메라 앱을 거치지 않고 **앱 내부에서 카메라 미리보기**를 엽니다.
- **촬영해서 첨부**를 누르면 웹앱이 사진을 JPG로 저장하고 즉시 입력창 위에 **사진 미리보기**를 표시합니다.
- 예전처럼 외부 카메라 앱을 사용하고 싶다면 카메라 창 안의 **휴대폰 카메라 앱 열기**를 누르세요. 일부 Android/PWABuilder 패키지는 촬영 후 파일 전달을 지원하지 않을 수 있습니다.
- 카메라 권한이 거부되었거나 앱 내부 카메라가 지원되지 않는 환경에서는 **앨범에서 선택** 버튼으로 기존 사진을 붙일 수 있습니다.
- 사진을 선택한 뒤 **보내기**를 눌러야 AI 질문이 전송됩니다. 촬영만으로 질문이 전송되지는 않습니다.
- 문서의 원본 사진은 브라우저 내에서 최대 1500px로 줄이고 JPG로 변환해 API 요청 크기를 제한합니다. 촬영 전후 카메라 영상은 서버에 스트리밍하지 않습니다.
- 기존 음성 인식 중복 방지와 학년별 힌트·학부모 모드 기능을 유지합니다.

## 갤럭시에서 직접 시험하기

1. GitHub 업데이트 ZIP의 `app.js`, `index.html`, `styles.css`, `sw.js`를 저장소 최상위에 업로드하고 Commit합니다.
2. Render 배포가 Live인지 확인하고, 갤럭시에서 앱을 완전히 종료했다가 다시 엽니다. 예전 화면이 계속 나오면 Chrome에서 같은 HTTPS 주소를 새로고침해 확인합니다.
3. **사진 첨부 → 카메라로 촬영**을 누릅니다. 카메라 권한 창이 나오면 허용합니다.
4. 카메라 미리보기에서 책의 문제를 화면에 넣고 **촬영해서 첨부**를 누릅니다.
5. **문제 사진 첨부됨** 썸네일을 확인한 다음 **보내기**를 누릅니다.
6. 앱 내부 카메라가 지원되지 않으면 **앨범에서 선택**을 누르거나 촬영한 사진을 갤러리에서 선택합니다.

## 촬영 화면이 나오지 않을 경우

- **카메라 권한:** 갤럭시 설정 → 앱 → Chrome(또는 설치한 앱) → 권한 → 카메라를 허용하세요. 브라우저의 해당 사이트 권한에서도 카메라를 허용하세요.
- **HTTPS:** https://로 시작하는 Render 주소에서 시험하세요.
- **카메라 앱만 실패:** `휴대폰 카메라 앱 열기` 버튼에서 촬영 후 사진이 돌아오지 않는다면, 앱 내부 카메라로 다시 찍거나 앨범에서 선택하세요.
- **Chrome 웹사이트는 되는데 APK만 안 됨:** PWABuilder/TWA 패키지의 권한이나 파일 선택 처리를 확인해야 하므로 APK/AAB를 새로 빌드해야 할 수 있습니다. 웹앱 수정만으로 모든 포장 앱의 네이티브 권한 문제를 해결할 수는 없습니다.

## 검증

`npm run check` 및 `npm test`로 코드·기존 학습 기능을 검사합니다. 앱 내부 카메라와 앨범 선택 시 모의 파일이 썸네일로 표시되는 브라우저 테스트도 진행했습니다. 실제 삼성 갤럭시 하드웨어 테스트는 별도로 필요합니다.
