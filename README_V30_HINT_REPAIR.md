# 생각별 선생님 v30 — 학년별 난이도와 힌트 검증 실패 복구

- 초1~2: 전문 용어를 피하고 생활 관찰 한 단계.
- 초3~4: 두 상황 비교 한 단계.
- 초5~6: 조건과 원인 사이 관계 한 단계.
- 수학·국어·사회·과학·영어 모두 기존 학년별 가이드 유지.
- 원문에 이미 제시된 결과를 다시 추측하게 묻지 않고, 실제로 묻는 원인·근거·풀이 첫 단계로 접근.
- 안전성 검토가 거절한 힌트는 같은 원문을 다시 분석하고 **최대 1회** 새로 만들고 검토. 여전히 실패하면 답을 공개하지 않고 실패 메시지만 표시.
- AI 연결·쿼터 오류까지 모두 ‘정확하지 않은 힌트’라고 안내하던 문구 변경.
- 기존 학부모 비밀번호, 힌트 기록, 정답 열람, UI 유지.

## 기존 갤럭시 배포 갱신

GitHub 저장소 최상위에서 `tutor-engine.mjs`, `server.mjs`, `app.js`, `sw.js`를 교체 → Commit → Render Live 확인 → 앱 완전 종료 후 다시 실행. Gemini 키 변경 불필요.

정답 노출이 완전히 사라진다고 보장할 수 없으며, 실제 Gemini 계정 호출은 별도로 검증해야 합니다. 안전 재작성 요청은 AI 사용량을 추가로 소모할 수 있습니다.
