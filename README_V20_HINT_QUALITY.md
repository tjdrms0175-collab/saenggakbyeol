# 생각별 선생님 v20: 짧고 구체적인 힌트 개선

현재 v19을 기반으로 문제·기록·음성 인식·Gemini 3단계 전환·힌트 무제한·5회 후 비밀번호 정답 보기를 유지했습니다.

## 변경 내용
- 키워드에 의존하지 않고 AI가 원문을 분석하는 기존 2단계 구조 유지
- 1차 생성: 원문에 적용되는 쉬운 원리 1문장 + 지금 할 행동과 질문 1문장
- 2차 검증: 사실 보존, 개념 설명, 행동 구체성, 중복, 정답 노출, 학년 수준 확인
- 질문만 되풀이하거나 '어떤 수를 먼저 쓸까요?' 같은 무의미한 힌트 거절
- 앞선 힌트의 반복을 검사. 단, 너무 유사한 경우 답을 억지로 출력하지 않고 다시 요청하도록 안내
- 힌트는 2문장, 권장 55~145자. 무리하게 긴 강의식 설명은 제공하지 않음

## GitHub/Render 업데이트
1. GitHub 저장소 최상위 파일 `tutor-engine.mjs`와 `server.mjs`만 교체
2. Commit changes → Render 새 배포 Live 확인
3. 갤럭시에서 '새 문제' 누르고 힌트를 시험
4. 기존 환경변수(GEMINI_API_KEY 등) 변경 불필요

## 테스트 및 주의 사항
`npm run check`와 `npm test`로 파일·모의 AI 응답을 확인할 수 있습니다.
AI가 2회(생성/검토) 호출되는 기존 구조는 유지됩니다. 실제 Gemini API 키를 사용한 실시간 품질 평가는 별도로 해야 합니다.
`hasUsefulHint`는 단순한 질문 반복, 일부 모호한 문구, 단위 변경 등을 차단하지만 AI가 사실상 잘못된 원리를 설명하는 모든 경우까지 보장하지는 않습니다.
