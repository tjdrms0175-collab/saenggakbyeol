# 생각별 선생님 v34 — 사진 문제 확인 후 힌트

## 변경 사항
- 사진을 첨부하고 보내기를 누르면 서버가 Gemini Vision으로 **문제·선택지를 먼저 문자로 추출**합니다.
- 아이가 인식된 문장을 확인하고, 잘못된 글자는 수정한 다음 `맞아요, 힌트 시작` 버튼을 누릅니다.
- 그 뒤에만 학년별 힌트를 생성합니다. AI가 추출에 실패하면 원문 대신 안내 문구로 힌트를 생성하지 않습니다.
- 사진은 학습 진행 확인용 식별 해시에 사용하며, 문제 문장을 확인한 뒤에는 **힌트 생성·검토 호출에서 이미지를 반복 전송하지 않고 텍스트만 사용**합니다.
- 기존 학습·학부모 정답(5회, 비밀번호), 자동 전환, 갤럭시 앱 기능은 유지합니다.

## GitHub 배포
`server.mjs`, `photo-reader.mjs`, `app.js`, `index.html`, `styles.css`, `sw.js`를 GitHub 저장소의 최상위 폴더에 업로드해 교체한 뒤 Render 배포 Live 확인 후 앱을 재실행하세요.

## 주의
- 서버의 `GEMINI_API_KEY`는 그대로 사용됩니다. 사진 인식에서 API 요청이 1회 이상 추가 발생할 수 있습니다.
- 인식된 글자는 틀릴 수 있으므로 반드시 사진과 비교해 확인해야 합니다.
- 사진 인식이 실패하면 이미지가 입력창에 남아 다시 시도하거나 텍스트로 직접 입력할 수 있습니다.
- `npm run test`의 사진 인식 테스트는 가짜 모델 응답을 사용하며 실제 갤럭시/Gemini API 호출은 별도 확인이 필요합니다.
