# 생각별 선생님 v29 — 5개 교과 전체 학년별 힌트 개선

이 버전은 v28 전체 기능(과목 자동 인식, 힌트 정답 비공개, 독립 AI 검토, 최종 답과 중간 답 분리, 학부모 모드, 음성 질문, Render Gemini 키, 모바일 PWA)을 유지합니다.

## 무엇이 달라졌나요?

기존에는 학년별 지침이 '쉬운 단어/쉬운 설명/원리 설명' 수준으로 짧았습니다. v29에서는 **선택한 학년에 대한 상세 교수법과 다섯 과목별 사고 단계를 매 AI 초안 생성·독립 검토 요청에 모두 포함**합니다. 과목 선택 버튼은 되살리지 않습니다. 질문이나 사진 내용으로 과목을 자동 판단합니다.

| 과목 | 초1~2 | 초3~4 | 초5~6 |
|---|---|---|---|
| 수학 | 블록·묶음·손가락으로 눈에 보이게 | 전체·부분·기준량을 구별하고 그림으로 비교 | 공식의 의미·미지수·단위를 근거로 한 단계 추론 |
| 과학 | 일상에서 본 현상 하나 관찰 | 두 상황 비교·조건 하나 변경 | 변인·원인과 결과·예측의 근거 |
| 영어 | 그림·동작·익숙한 단어에서 추측 | 주어·동작·시간·문맥 단서 구별 | 시제·문장 구조·연결어가 뜻에 미치는 영향 |
| 국어 | 인물·행동·낱말 하나 찾기 | 문단·마음·중심 생각의 근거 찾기 | 주장과 근거·글의 구조·표현 효과 |
| 사회 | 학급 약속·가족·동네 비유 | 지역사회와 역사·기관 역할 비교 | 제도와 권한, 역사 원인·결과 및 근거 |

이 기준은 학생의 **지능이나 능력을 판정하는 규칙이 아닙니다**. 아이가 막힐 때는 학년과 무관하게 더 기초적인 개념으로 내려갑니다. 문제의 수·단위·대상과 최종 정답은 변경하거나 노출하지 않습니다.

독립 검토 AI는 `grade_fit`(학년에 맞는가)과 `subject_method_fit`(실제 과목에 맞는가)를 보고하고, 불일치를 명시한 일반 힌트는 서버가 표시하지 않습니다. 중간/최종 정답 판정이 확실한 경우에는 **그 다음 힌트의 부적절함 때문에 칭찬이 취소되지 않도록** 이전 동작을 유지했습니다.

## Render / GitHub 업데이트

1. 기존 GitHub 저장소에서 `tutor-engine.mjs`를 새 파일로 교체합니다.
2. 선택적으로 `package.json`과 새로운 `grade-all-subjects.test.mjs`도 교체/추가하면 최신 테스트를 실행할 수 있습니다.
3. `Commit changes`를 누르고 Render 배포가 `Live`인지 확인합니다.
4. 앱을 완전히 닫고 열어 학년별로 같은 문제를 각각 질문해 보세요.

`GEMINI_API_KEY`와 나머지 Render 환경변수는 바꿀 필요가 없습니다. AI 설정, 과목 버튼, 정답 확인 및 학부모 모드의 UI도 변경하지 않았습니다.

## 테스트와 한계

`npm run check`, `npm test` — 기존 학습/서버 관련 테스트 62개 + 새 학년·과목·검토 테스트 19개 = **81개 통과**.
이 테스트는 프롬프트/검증 경로를 확인합니다. 실제 Gemini 응답의 정답 노출·학년 적합성·교과 정확성을 100% 보장하지 않으므로 배포 후 5개 과목에서 학년별로 동일 문제를 반복 시험하세요.
